- Source URL or user-described signal intake.
- Opportunity hash creation.
- Explicit operator-review state.

- Public-safe receipt link.

- Product-event spine.

## Deferred

- Automated scoring or package claims.
- Full CeeCee voice or chat runtime.
- Automated publishing.
- Bounties, payouts, creator marketplace, and payment automation.
- Multi-tenant workspaces.
- Durable Object coordination.
- Scheduled public-signal ingest.
- Public access to private engine prompts, doctrine, routes, or infrastructure.

## Public truth rule

A request can be described as received, hashed, queued, or awaiting review only when the corresponding record exists. A package can be described as compiled only after an operator records the package. A public receipt can be described as issued only after approval creates the sanitized receipt surface.
